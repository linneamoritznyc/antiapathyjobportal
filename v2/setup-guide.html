Koppla din Gmail

För att automatiskt spara utkast till din Gmail behöver du skapa ett eget Google Cloud-projekt. Det tar cirka 10-15 minuter.

Varför behöver jag göra detta?

Vi vill inte hantera dina Gmail-uppgifter. Genom att skapa ditt eget Google Cloud-projekt har du full kontroll över åtkomsten och kan återkalla den när som helst. Dina uppgifter lagras aldrig hos oss.

1

Skapa ett Google Cloud-projekt

  1. 1. Gå till console.cloud.google.com
  2. 2. Logga in med ditt Google-konto (samma som din Gmail)
  3. 3. Klicka på "Select a project" högst upp
  4. 4. Klicka "New Project"
  5. 5. Namnge projektet (t.ex. "Jobbsökning")
  6. 6. Klicka "Create"
2

Aktivera Gmail API

  1. 1. Gå till Gmail API-sidan
  2. 2. Se till att rätt projekt är valt högst upp
  3. 3. Klicka "Enable"
3

Konfigurera OAuth Consent Screen

  1. 1. Gå till OAuth consent screen
  2. 2. Välj "External" och klicka "Create"
  3. 3. Fyll i:
    • App name: Jobbsökning
    • User support email: Din e-post
    • Developer contact: Din e-post
  4. 4. Klicka "Save and Continue"
  5. 5. På "Scopes" - klicka bara "Save and Continue"
  6. 6. På "Test users" - klicka "Add Users" och lägg till din Gmail-adress
  7. 7. Klicka "Save and Continue"
4

Skapa OAuth-credentials

  1. 1. Gå till Credentials
  2. 2. Klicka "Create Credentials" → "OAuth client ID"
  3. 3. Application type: "Web application"
  4. 4. Name: Jobbsökning Web
  5. 5. Under "Authorized redirect URIs", lägg till:
    https://platsbanken-ai.vercel.app/api/gmail/callback
  6. 6. Klicka "Create"
  7. 7. Kopiera Client ID och Client Secret som visas!
5

Klistra in i appen

Gå tillbaka till appen och klistra in dina credentials i inställningarna.
