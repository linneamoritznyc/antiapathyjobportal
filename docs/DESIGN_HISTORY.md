# Anti-Apathy Portal - Design History

## Original Design (v1)

![Original Layout](./original-layout.png)

### Features
- **Header**: "Anti-Apathy Portal" med tagline "En uppgift i taget. Du klarar detta!"
- **Status indicator**: "Ej ansluten" / "Ansluten" uppe till höger
- **4 stat-kort**:
  - VÄNTANDE JOBB (lila)
  - SKICKADE (grön)
  - INTERVJUER (blå)
  - DEADLINE IDAG (röd)
- **Central CTA**: Stor "Scrapa Nya Jobb" knapp
- **Enkel footer**: "Scrapa fler jobb" länk

### Design Philosophy
- "En uppgift i taget" - minimera cognitive load
- Fokus på nästa steg, inte alla möjligheter
- Lugna färger, inga överväldigande element
- Perfekt för användare med jobbsökningsångest

---

## Current Design (v2)

### Added Features
- Multi-user support med Supabase Auth
- Tabs: Jobb, Mina CV, Ansökningar
- Master CV Editor
- Konto-sida med profil/inställningar
- GDPR compliance (export/delete)
- CV-vibes per bransch

### Design Goal
Behåll den "anti-apathy" känslan från v1 men med mer funktionalitet bakom kulisserna.
