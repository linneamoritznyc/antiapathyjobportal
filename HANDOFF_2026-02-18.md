# Handoff: Status 18 februari 2026

## Vad är den här appen?

**Anti-Apathy Job Portal** är ett AI-drivet jobansökningsverktyg byggt specifikt för Linnea Moritz, en neurodivergent jobbsökare i Sverige. Appen tar bort friktionen i jobbsökandet genom att:

1. **Scrapa Platsbanken** automatiskt efter relevanta jobb
2. **Matcha jobb mot rätt CV** (Linnea har 8 branschspecifika CVer)
3. **Generera personliga personliga brev** via Claude API (Anthropic)
4. **Skapa Gmail-drafts** med rätt CV bifogat, redo att skicka

Linnea är neurodivergent och behöver minimal friktion — appen ska göra allt tungt arbete.

## Hur Claude-sessioner fungerar (viktigt!)

Varje gång en ny Claude-session startar i detta repo, är mina ändringar på en **feature branch** (`claude/...`). De hamnar INTE på main förrän du mergar PRn på GitHub.

**Detta betyder:**
- Jag skriver kod → commitar till feature branch
- Du mergar PRn → Vercel deployas automatiskt
- Du behöver göra **hard refresh** (Ctrl+Shift+R) i webbläsaren för att se ändringarna

## App-funktioner (per 18 feb 2026)

### Fliken "Jobb" (huvudfliken)
- Visar ett jobb i taget (swiper-stil)
- Vänster kolumn: fullständig jobbbeskrivning (HTML-renderad)
- Höger kolumn: titel, företag, plats, deadline, taggar, knappar
- Progress bar visar "X av Y jobb"
- Filter på prioritet (Akut/Snart/Ny) och fritextsök
- "Spara" knapp — sparar jobb till "Sparade jobb"-listan

### Generera ansökan
1. Klicka "Generera ansökan" på ett jobb
2. Backend (Claude API) genererar personligt brev på svenska
3. Om Gmail är kopplat: skapar automatiskt Gmail-draft med:
   - Subject: `Ansökan: [Jobbtitel] – Linnea Moritz`
   - Body: det genererade personliga brevet
   - Bilaga 1: `Personligt_Brev_Linnea_Moritz.pdf` (genererad PDF)
   - Bilaga 2: rätt bransch-CV (t.ex. `CV_Linnea_Moritz_Restaurang_Cafe.pdf`)

### CV-matchning (8 kategorier)
| Kategori | CV-fil |
|----------|--------|
| restaurant | CV_Linnea_Moritz_Restaurang_Cafe.pdf |
| retail | CV_Linnea_Moritz_Butik_Kassa.pdf |
| customerservice | CV_Linnea_Moritz_Kundtjanst.pdf |
| tech | CV_Linnea_Moritz_Tech_Kontor.pdf |
| healthcare | CV_Linnea_Moritz_Vard_Omsorg.pdf |
| industri | CV_Linnea_Moritz_Industri_Tradgard.pdf |
| contentmoderation | CV_Linnea_Moritz_Content_Moderation.pdf |
| art | CV_Linnea_Moritz_Konst_Kultur.pdf |

### Fliken "Mina CV"
- Visar Linneas 8 CV-versioner
- CV-data lagras i Supabase (user_cvs, user_experiences, etc.)

### Fliken "Ansökningar"
- Historik över skickade ansökningar
- Status: Skickad / Intervju / Avslag / Väntar

### Fliken "Statistik"
- Antal jobb, skickade ansökningar, intervjuer, deadlines idag

### Fliken "Profil"
- Koppling till Gmail OAuth (för att skapa drafts)
- E-postsignatur (sparas i Supabase)
- Preferenser

### Gmail OAuth-flöde
- Linnea kopplar Gmail i Profil-fliken
- OAuth-tokens sparas i Supabase (gmail_tokens-tabellen)
- Backend använder tokens för att skapa drafts via Gmail API
